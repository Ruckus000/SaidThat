# Phase 0 / wild-pack card sources

## Wild-pack rewrite (2026-08-02)

Research method for [`exciting-tweet-candidates-2026-08-02.md`](exciting-tweet-candidates-2026-08-02.md): **aggregator-first**, then owner Y/N. Named tweets were extracted from chaotic / meltdown / awkward roundups, then filtered for fame + crazy-statement + **self-contained** + **exciting (not merely awkward)** + readable chaos + no brand-expected voice + no hate/crisis/misinfo spectacles. Owner review further cut typo-memes (covfefe), context-dependent shade, and finance-event lore that isn't forehead-exciting. Ye / Trump / SZA / Elon news hits filled gaps when lists under-covered them.

**Not legal clearance.** Authentic wording is taken from secondary reporting; verify before store launch.
